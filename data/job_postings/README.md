# job_postings/

공고 한 건당 두 파일, 준비한 공고는 세 파일.
- `YYYY-MM-DD_회사_포지션.md`: 링크, 수집일·수집 방법, 공고 원문 전체.
- `YYYY-MM-DD_회사_포지션.eval.md`: 평가(`modes/evaluate.md` 형식). 조건 판정, 요구사항 대응표, 맞춤 이력서 계획, 면접 준비.
- `YYYY-MM-DD_회사_포지션.prep.yaml`: 준비 자료(`modes/prep.md`, 예시 `examples/prep.example.yaml`). 회사·직무 조사, 전형과 시험, 예상 질문, 더 준비할 것. 공고 현황표가 이 파일로 공고별 준비 쪽을 만든다.
맞춤 이력서를 만들면 원문 파일에 사용한 yaml 이름을 적는다. 결과를 쌓아 두면 어느 버전이 어떤 회사에서 통과하는지 비교할 수 있다.
